# 3. Jatiswara

Jatiswaras combine rhythmic syllables and swara passages. Each score should
record raga, tala and anga grouping, eduppu, tempo, source, and the exact
relationship between jati syllables and notes.

## Writing checklist

- Preserve jati syllables exactly as provided by the source.
- Keep jati and swara text distinguishable and aligned to their notes.
- Show tala subdivisions using the project dashed-barline convention.
- Document nadai/gati and any tempo change.
- Mark octave changes with the standard swara styling.
