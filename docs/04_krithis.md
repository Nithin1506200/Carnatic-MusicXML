# 4. Kritis

This section holds kritis (also commonly written krithis or kruthis) arranged
for alto saxophone.

## Required structure

Record the title, language, composer, raga, tala, eduppu, source, and available
sections. Preserve the source order of `pallavi`, `anupallavi`, and
`charanam`; document any omitted or repeated sangati.
