# 6. Bhajans

This section holds bhajane/bhajan and devotional repertoire arranged for alto
saxophone.

## Required structure

Record the title, language, attributed composer when known, raga or melodic
basis, tala, source, refrain structure, and verse order. Use `Traditional` or
`Unknown` only when supported; do not invent an attribution.

When several commonly sung melodic versions exist, identify the version or
source used by the score.
