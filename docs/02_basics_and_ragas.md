# 2. Basic Notes and Raga List

This section contains foundational swara exercises, alankaras, beginner
geethams, and a verified raga reference.

## Default swara map

For the project's written `Sa = G` alto-saxophone setup:

| Swarasthana | Written pitch |
| ----------- | ------------- |
| S           | G             |
| R1          | A-flat        |
| R2 / G1     | A             |
| R3 / G2     | B-flat        |
| G3          | B             |
| M1          | C             |
| M2          | C-sharp       |
| P           | D             |
| D1          | E-flat        |
| D2 / N1     | E             |
| D3 / N2     | F             |
| N3          | F-sharp       |
| Upper S     | G             |

Enharmonic swarasthanas share a written pitch in twelve-tone notation but keep
their raga-specific swara names.

## Raga list

Only add a raga after verifying its arohana and avarohana from an authoritative
source. Vakra phrases, anya swaras, characteristic prayogas, and source
variants must not be reduced to an oversimplified scale.

| Raga            | Classification                | Arohana                | Avarohana              | Current use            |
| --------------- | ----------------------------- | ---------------------- | ---------------------- | ---------------------- |
| Mayamalavagowla | Melakarta 15                  | `S R1 G3 M1 P D1 N3 S` | `S N3 D1 P M1 G3 R1 S` | Foundational exercises |
| Malahari        | Janya raga of Mayamalavagowla | `S R1 M1 P D1 S`       | `S D1 P M1 G3 R1 S`    | Sri Gananatha          |
